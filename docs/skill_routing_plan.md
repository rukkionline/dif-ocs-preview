# Skill Routing Plan

- task mode: full-build

## Selected skills

- `reference-research-analyst`: зафиксировать точные визуальные и поведенческие свойства единственного эталона.
- `frontend-implementation-engineer`: подготовить безопасную статическую копию исходного HTML.
- `automated-render-qa`: получить desktop/mobile скриншоты оригинала и копии, проверить рендер и консоль.
- `accessibility-semantic-qa`: проверить, что защитные изменения не ухудшили семантику и доступность.
- `visual-qa-reviewer`: сравнить отрисованную копию с контрольными снимками.
- `performance-seo-technical-qa`: проверить публичную сборку, `noindex`, ресурсы и технические ошибки.

## Skipped skills

- `frontend-design-foundation`: дизайн уже полностью определен пользовательским референсом; создавать новые направления нельзя.
- `taste-anti-slop-critic`: задача требует буквального воспроизведения, а не оценки или изменения вкусового направления.
- `uiux-system-builder`: исходная Tilda-страница уже содержит полный CSS/компонентный контракт; отдельная токенизация ухудшит точность.
- `seo-content-layout-designer`: preview намеренно закрывается от индексации и не является новой SEO-страницей.
- `content-proof-editor`: текст переносится без изменения, новые утверждения не добавляются.

## Required inputs

- URL эталона: https://dif.ocs.ru/
- Контрольные скриншоты desktop/mobile.
- HTML и список внешних ресурсов исходной страницы.
- Доступный внешний статический хостинг.
