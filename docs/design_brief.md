# Design Brief

- Тип страницы: одностраничный event-лендинг.
- Цель: приватно-публичный просмотр точной демонстрационной копии по внешней ссылке.
- Аудитория: заказчик и его приглашенные участники.
- Гео/язык: Россия, русский.
- Источник контента и дизайна: https://dif.ocs.ru/.
- Обязательные блоки: все блоки, меню, бегущие строки, изображения, квиз, popup/анкоры и footer исходника.
- Стек: статический HTML/CSS/JS с исходными Tilda CDN-ресурсами.
- Формат: GitHub Pages.
- Ограничения: один в один; без редизайна и переписывания контента; формы не отправляют данные; preview не индексируется.
- Приемка: сравнение реальных рендеров 1440 px и 390 px, проверка внешнего URL.
