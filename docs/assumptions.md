# Assumptions

- Пользователь имеет право использовать предоставленный публичный референс для демонстрационной копии.
- Под «внешней ссылкой» понимается публичный HTTPS URL, который можно передать другому человеку.
- Для pixel-perfect результата допустимо использовать публичные CDN-ресурсы исходной Tilda-страницы.
- Фактическая отправка форм и аналитических событий не требуется для демонстрации и блокируется ради безопасности данных.
- Копия публикуется с `noindex,nofollow` и без канонической ссылки на исходный домен.
