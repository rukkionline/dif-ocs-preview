# DIF OCS Preview

Статическая демонстрационная копия публичного лендинга <https://dif.ocs.ru/>.

## Команды

```bash
npm run build
npm run check
npm run serve
```

Локальный URL: <http://127.0.0.1:4317/>.

## Безопасность preview

- поисковая индексация запрещена через meta robots и `robots.txt`;
- статистика Tilda отключена;
- идентификаторы form services удалены;
- отправка формы блокируется на клиенте;
- ссылки на отдельные городские страницы ведут на оригинальный домен.
