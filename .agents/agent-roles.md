# Agent Roles

## Codex
Использовать для кода, тестов, рефакторинга, поиска багов, работы с файлами и реализации небольших/средних задач.

## Claude Code
Использовать для дизайн-аудитов, сложных ТЗ, текстов, смысловой структуры страниц, UX/SEO ревью.

## Orca
Использовать как оболочку управления агентами, worktree-оркестратор, Git/source-control слой и рабочую панель задач.
