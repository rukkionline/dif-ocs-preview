# Workflow

1. Загрузить контекст через AGENTS.md / CLAUDE.md.
2. Найти активную задачу в .agents/current-task.md.
3. Прочитать task-файл и определить mode.
4. Изучить релевантные файлы по .agents/context-map.md.
5. Составить план, scope, риски и проверки.
6. Реализовать маленькими шагами в рамках scope.
7. Проверить build/lint/test или явно указать причину пропуска.
8. Подготовить summary, список файлов, риски и ручные проверки.
9. Для крупной задачи сохранить отчет в .agents/reports/.
10. Важные решения дописать в memory.md или оформить ADR в decisions/.
