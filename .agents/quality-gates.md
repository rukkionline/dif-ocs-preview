# Quality Gates

## Before implementation
- [ ] Есть файл задачи в .agents/tasks/.
- [ ] В задаче указан mode.
- [ ] Есть acceptance criteria.
- [ ] Scope понятен.
- [ ] Риски и проверки определены.

## Before review
- [ ] Изменения соответствуют задаче.
- [ ] Нет лишних файлов.
- [ ] Нет нарушения .agents/rules.md.
- [ ] Есть diff summary.
- [ ] Build/lint/test пройдены или причина пропуска указана.

## Before merge
- [ ] Пользователь принял результат.
- [ ] Отчет сохранен, если задача крупная.
- [ ] Важные решения записаны.
- [ ] Приватные данные не попали в публичные файлы.
