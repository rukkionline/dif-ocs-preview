# Полная preview-копия DIF OCS

- mode: implement
- status: completed
- priority: high
- risk: medium

## Scope

- Снять контрольные рендеры публичного лендинга https://dif.ocs.ru/.
- Сохранить статическую копию страницы с исходной версткой, стилями, ресурсами и клиентскими анимациями.
- Не отправлять данные форм в инфраструктуру исходного сайта.
- Добавить запрет поисковой индексации preview.
- Проверить desktop и mobile рендеры, консоль, ссылки и адаптивность.
- Опубликовать по внешнему URL и подтвердить доступность.

## Acceptance criteria

- Первый экран и основные секции совпадают с оригиналом по структуре, типографике, цветам, изображениям и анимациям.
- Страница доступна по публичному HTTPS URL без авторизации.
- Внешние ссылки открываются как на оригинале.
- Формы визуально и интерактивно работают, но фактическая отправка данных заблокирована.
- На странице есть `noindex,nofollow`, а публичный preview не объявляет канонический URL оригинала.
- Проверены как минимум 1440 px и 390 px.

## Definition of done

- Код находится в отдельном git-репозитории.
- GitHub Pages отвечает HTTP 200.
- Созданы QA-отчеты и evidence manifest.
- Нет открытых Critical/High дефектов.

## Риски

- Tilda может ограничивать часть клиентских функций вне исходного домена.
- Динамические формы и аналитика не должны отправлять данные в OCS/Tilda.
- CDN-ресурсы остаются внешней зависимостью для максимальной визуальной идентичности.
