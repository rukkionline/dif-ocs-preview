# Project Context

## Название
DIF OCS Preview

## Цель
Создать визуально идентичную демонстрационную копию публичного лендинга https://dif.ocs.ru/ и опубликовать ее по внешнему URL.

## Аудитория
Заказчик и приглашенные им участники просмотра.

## Бизнес-модель / сценарий
Статический preview без сбора и отправки пользовательских данных.

## Стек
Статический HTML/CSS/JS, ресурсы Tilda CDN, GitHub Pages.

## Что нельзя менять без согласования
- стек;
- архитектуру;
- основной пользовательский сценарий;
- продуктовые и брендовые ограничения.
