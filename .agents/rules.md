# Agent Rules

## Язык
- Отвечать на русском, если пользователь явно не попросил иначе.
- Комментарии, отчеты и summary писать на русском.

## Режимы работы
- mode: plan_only - только анализ и план, файлы не менять.
- mode: audit_only - только аудит, файлы не менять.
- mode: implement - реализация по подтвержденной задаче и scope.
- mode: fix_only - исправлять только заявленную проблему.
- mode: review - проверять diff и риски, не менять файлы.

## Работа с файлами
- Перед изменением изучить структуру проекта и релевантный контекст.
- Не удалять файлы без явного разрешения.
- Массовые изменения - только отдельной задачей.
- Архитектуру не менять без согласования.
- Не превращать локальный фикс в переписывание проекта.

## Git
- Учитывать worktree-модель ORCA.
- Перед крупными правками показать список затрагиваемых файлов.
- После правок дать diff summary.
- Не пушить без разрешения или без проектного workflow, который явно это требует.

## Контекст и память
- .agents/memory.md только дописывать.
- Полные задачи хранить в .agents/tasks/.
- Отчеты писать новыми файлами в .agents/reports/.
- Решения писать отдельными файлами в .agents/decisions/.
- Приватные данные хранить только в приватных gitignored файлах.
