# Agent Rules — dif-ocs-preview

## Язык

- Отвечать на русском, если пользователь явно не попросил иначе.
- Комментарии, отчёты и summary писать на русском.

## Режимы работы

- `plan_only` — только анализ и план, файлы не менять.
- `audit_only` — только аудит, файлы не менять.
- `implement` — реализация по подтверждённой задаче и scope.
- `fix_only` — исправлять только заявленную проблему.
- `review` — проверять diff и риски, не менять файлы.

## Работа с файлами

- Перед изменением изучить структуру проекта и релевантный контекст.
- Не удалять файлы без явного разрешения.
- Массовые изменения — только отдельной задачей.
- Не превращать локальный фикс в переписывание проекта.
- Не переписывать существующие инструкции, отчёты и evidence ради единообразия.

## Git

- Работать в отдельной ветке; в `main` ничего не писать напрямую.
- Перед крупными правками показать список затрагиваемых файлов.
- После правок дать diff summary.
- Не пушить и не мержить без разрешения или проектного workflow, который это явно требует;
  force-push, удаление refs и `git reset --hard` запрещены.

## Контекст и память

- `.agents/memory/index.md` — канонический индекс; topics загружаются по ссылкам.
- `.agents/memory.md` (если есть) — append-only legacy; прежние записи не переписывать.
- Полные задачи хранить в `.agents/tasks/`.
- Отчёты писать новыми файлами в `.agents/reports/`.
- Решения писать отдельными файлами в `.agents/decisions/`.
- Приватные данные хранить только в приватных gitignored файлах.

## Owner gates

Без явного разрешения владельца запрещены deploy, push/merge в `main`, DNS, отправка URL
на индексацию, изменение robots/sitemap на production, расходы, внешние сообщения,
работа с секретами и публикация новых юридических/коммерческих утверждений.
