# GitHub-first: источник истины и write-gate

Контракт проекта. Обязателен для любых изменений в этом репозитории.
Машиночитаемая часть: `.source-of-truth.json`.

- Канонический репозиторий: `rukkionline/dif-ocs-preview` на GitHub; принятая ветка — `main`.
- `main` — принятая версия; работа ведётся в отдельной ветке и принимается только через PR.
- Свежий GitHub `main` важнее локального checkout.
- Статус исходников и production намеренно не подтверждается: неизвестное нельзя объявлять восстановленным.
- Перед push проверяются точный diff, secrets/PII/runtime-файлы; секреты, `.env`, базы и логи не коммитятся.
- Каждый финал фиксирует repo, branch, commit SHA, paths, tests и PR; pushed не равно accepted.
- Production допускается только по approved immutable SHA с backup и rollback.
- Более строгие проектные правила сохраняются и имеют приоритет.
