# AGENTS.md

На момент добавления GitHub-first контракта у этого репозитория не было собственного
`AGENTS.md`. Этот файл — короткая точка входа, а не замена project-local правил.

1. Сначала прочитать уже существующие инструкции репозитория (`.agents/`, `README.md`,
   `RUNBOOK.md`, `docs/` и любые другие действующие правила). Они сохраняются как есть;
   этот файл их не отменяет и не переписывает.
2. GitHub — канонический источник истины: `main` — принятая версия, работа — branch + PR.
3. Контракт и write-gate: [`.agents/github-source-of-truth.md`](.agents/github-source-of-truth.md),
   машиночитаемая часть: [`.source-of-truth.json`](.source-of-truth.json).

Новых продуктовых ограничений этот файл не вводит.
